# Triage 标签

将 Matt skills 使用的五种角色映射到 GitHub Issues 的实际标签。标签字符串保留英文，说明使用中文。

| Skill 角色 | GitHub 标签 | 含义 |
|---|---|---|
| `needs-triage` | `needs-triage` | 维护者需要评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 需求清晰，适合 agent 实现 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不安排实施 |

Skill 提到某种角色时，使用本表中的对应标签。未来需要自定义名称时修改“GitHub 标签”列，并确保 tracker 中存在相应标签。
